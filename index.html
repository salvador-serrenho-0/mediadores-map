⚙️ Configurar sincronização

Para partilhar o estado de visitas entre toda a equipa, precisas de uma Google Sheet como base de dados. É grátis e leva 2 minutos.

  1. Abre sheets.new no browser
  2. Vai a Extensões → Apps Script
  3. Cola o código do ficheiro apps-script.js que está no mesmo repositório
  4. Clica Implementar → Nova implementação → App Web
  5. Em "Quem tem acesso" escolhe "Qualquer pessoa"
  6. Copia o URL da implementação e cola abaixo

💡 Podes configurar isto mais tarde nas definições. Sem a Sheet, cada telemóvel guarda o seu estado localmente.
